# billim-app 기획서

> 이 문서는 **무엇을, 왜** 만드는지 적는다. 개발 규칙은 `CLAUDE.md`에 있다.
> 기획이 바뀌면 코드보다 먼저 [결정 기록](#9-결정-기록)에 한 줄을 적는다.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 이름 | billim-app |
| 한 줄 소개 | 읽고 싶은 책이 내 주변 공공도서관에 있는지, 대출할 수 있는지 가까운 순으로 한 번에 확인한다 |
| 대상 플랫폼 | 모바일 웹 우선 (휴대폰 브라우저, 세로 화면 기준) |
| 데이터 출처 | 도서관 정보나루 Open API (data4library.kr) |
| 배포 주소 | https://billim-app.vercel.app (Vercel Hobby, `main` push 시 자동 배포) |
| 꼭 지킬 제약 | 무료 서비스와 무료 플랜만 쓴다. 과금 API는 쓰지 않는다 |

## 2. 목표

- 도서관 홈페이지를 하나씩 열어 보지 않아도, **가까운 도서관 중 어디에 가면 빌릴 수 있는지** 바로 알 수 있다.
- 밖에서 휴대폰 한 손으로 쓸 수 있을 만큼 단순하다.

## 3. MVP: 이번 버전에서 꼭 되는 것

| # | 기능 | 설명 |
|---|---|---|
| F1 | 책 검색 | 제목이나 저자로 검색하고 결과 목록에서 책 1권을 고른다 |
| F2 | 현재 위치 | 브라우저 위치 권한으로 내 위치를 얻는다 |
| F3 | 소장 도서관 거리순 목록 | 고른 책을 가진 주변 도서관을 내 위치에서 가까운 순으로 보여 준다. 확인한 도서관 중 대출 가능한 곳을 먼저 보여 준다. 항목마다 거리, 대출 가능 여부(색과 글자)가 보인다 |
| F4 | 도서관 상세 | 목록 항목을 누르면 도서관 이름, 거리, 대출 가능 여부, 주소, 전화, 홈페이지 링크가 보인다 |
| F5 | 즐겨찾기 (책, 도서관) | 책과 도서관을 즐겨찾기에 넣고 뺀다. 즐겨찾기한 책은 바로 주변 도서관 확인으로 간다. 로그인 없이 이 기기에만 저장한다 |

## 4. 이번 버전에서 안 하는 것

새 기능이 이 목록과 부딪히면 먼저 짚고 결정 기록에 남긴다.

- 회원가입과 로그인, 여러 기기 간 즐겨찾기 동기화
- 대출 예약이나 상호대차 신청 (도서관 홈페이지 링크만 제공)
- 도서관 홈페이지 크롤링 (정보나루 API 데이터만 쓴다)
- 인기 도서, 추천 도서, 독서 기록
- 알림 (예: "대출 가능해지면 알려 줘")
- 길찾기 경로 안내
- 지도 표시 (다음 버전에서 한다. 이번에는 거리순 목록만 보여 준다)
- 네이티브 앱과 앱스토어 배포, PWA 설치
- 데스크톱 전용 레이아웃 (깨지지만 않으면 된다)

## 6. 화면별 명세

### S1. 홈 (검색)

```
┌─────────────────────────────┐
│ billim                [★ 2] │  ← 즐겨찾기 개수, 누르면 S5
│                             │
│  어떤 책을 빌리고 싶나요?   │
│ ┌─────────────────────┐ ┌─┐ │
│ │ 제목 또는 저자      │ │🔍│ │
│ └─────────────────────┘ └─┘ │
│                             │
│  도서관 정보나루 데이터 기준│
└─────────────────────────────┘
```

- 보이는 것: 검색창, 즐겨찾기 바로가기
- 할 수 있는 것: 키워드 검색 (빈 키워드는 검색하지 않음), 즐겨찾기로 이동
- 빈 상태: 해당 없음

### S2. 검색 결과

```
┌─────────────────────────────┐
│ ← [ 채식주의자          🔍] │
│ 검색 결과 12권              │
│ ┌────┐ 채식주의자        ☆  │
│ │표지│ 한강 · 창비 · 2007   │
│ └────┘                      │
│ ┌────┐ ...               ★  │
│ │표지│                      │
│ └────┘                      │
│        [ 더 보기 ]          │
└─────────────────────────────┘
```

- 보이는 것: 표지, 제목, 저자, 출판사, 출판 연도, 즐겨찾기 별
- 할 수 있는 것: 책 선택 → S3, 별 눌러 즐겨찾기 넣기/빼기, 더 보기
- 빈 상태: "'{키워드}'에 맞는 책을 찾지 못했어요. 제목이나 저자 이름을 바꿔 검색해 보세요."
- 오류: "책 정보를 불러오지 못했어요. 잠시 후 다시 시도해 주세요." + [다시 시도]

### S3. 위치 안내 (권한 거부 또는 위치 실패 시에만)

```
┌─────────────────────────────┐
│ ←                           │
│        📍                   │
│  내 위치를 알아야 가까운    │
│  도서관을 찾을 수 있어요.   │
│                             │
│  브라우저 설정에서 위치     │
│  권한을 허용한 뒤 다시      │
│  시도해 주세요.             │
│      [ 다시 시도 ]          │
└─────────────────────────────┘
```

- 할 수 있는 것: 다시 시도, 뒤로 가기
- 위치 좌표는 저장하지 않는다
- 원인별 안내 문구 (첫 줄 "내 위치를 알아야 가까운 도서관을 찾을 수 있어요."는 같다)
  - 권한 거부: "브라우저 설정에서 위치 권한을 허용한 뒤 다시 시도해 주세요."
  - 위치를 못 찾음, 시간 초과: "위치를 찾지 못했어요. 잠시 후 다시 시도해 주세요."
  - 위치 기능 없음: "이 브라우저에서는 위치를 확인할 수 없어요." ([다시 시도] 없이 뒤로 가기만)

### S4. 소장 도서관 거리순 목록

```
┌─────────────────────────────┐
│ ← 채식주의자             ☆  │
│ 소장 293곳 · 확인한 5곳 중  │
│ 대출 가능 2곳               │
│ 확인 시각 15:42             │
│ ─────────────────────────── │
│ ○○시립도서관      0.8km     │
│     ● 대출 가능             │  ● 초록: 대출 가능
│ □□작은도서관      2.5km     │  ● 회색: 대출 중
│     ● 대출 가능             │  ● 노랑: 확인 실패
│ △△구립도서관      1.2km     │
│     ● 확인 실패             │
│ ...                         │
│        [ 더 보기 ]          │
└─────────────────────────────┘
```

- 보이는 것: 목록(이름, 거리, 상태), 요약 한 줄, 확인 시각(우리가 대출 여부를 조회한 시각). 상태는 색만으로 구분하지 않고 글자도 함께 쓴다
- 가까운 소장 도서관 5곳씩 보여 준다. [더 보기]를 누르면 다음 5곳의 대출 여부만 새로 확인한다
- 할 수 있는 것: 목록 항목 탭 → S4-1, 책 즐겨찾기 토글, 더 보기
- 정렬: 지금까지 확인한 도서관을 대출 가능 → 대출 중 → 확인 실패로 묶고, 묶음 안에서는 직선거리가 가까운 순. [더 보기]로 새로 확인한 대출 가능 도서관은 기존 대출 중 항목보다 위로 들어간다
- 빈 상태: "주변 도서관에는 이 책이 없어요." 
- 오류: "도서관 정보를 불러오지 못했어요." + [다시 시도]

### S4-1. 도서관 상세 (아래에서 올라오는 시트)

```
├─────────────────────────────┤
│ ○○시립도서관     0.8km   ☆  │  ← 도서관 즐겨찾기
│ ● 대출 가능                 │
│ 주소: ...                   │
│ 전화: 02-000-0000  [전화]   │
│ [ 도서관 홈페이지 열기 ↗ ]  │
└─────────────────────────────┘
```

### S5. 즐겨찾기

```
┌─────────────────────────────┐
│ ← 즐겨찾기                  │
│ [ 책 (2) ] [ 도서관 (1) ]   │  ← 탭
│ ┌────┐ 채식주의자        ★  │
│ │표지│ 한강                 │
│ └────┘   [ 주변에서 찾기 ]  │
└─────────────────────────────┘
도서관 탭:
│ ○○시립도서관             ★  │
│ 주소 · 전화                 │
```

- 할 수 있는 것: 책 → 주변에서 찾기(S4), 도서관 → 상세 시트(S4-1), 별 눌러 빼기
- 빈 상태 (책): "아직 즐겨찾기한 책이 없어요. 검색 결과에서 ☆를 눌러 저장해 보세요."
- 빈 상태 (도서관): "아직 즐겨찾기한 도서관이 없어요. 도서관 상세에서 ☆를 눌러 저장해 보세요."
- 도서관 탭에서는 특정 책의 대출 가능 여부를 보여 주지 않는다 (책을 고른 뒤 S4에서 확인)
- 안내: "즐겨찾기는 이 기기의 이 브라우저에만 저장돼요."
- 저장 실패 (저장소가 막혀 있거나 꽉 참): "이 브라우저에서는 즐겨찾기를 저장할 수 없어요." 별 상태는 바꾸지 않는다. S2와 S4-1의 별에도 같은 문구를 쓴다

## 7. "다 됐다"의 기준

공통: `npx tsc --noEmit`, `npm run lint`, `npm test`, `npm run build`가 모두 통과한다.

| 기능 | 완료 기준 | 직접 확인할 것 |
|---|---|---|
| F1 책 검색 | 실제 정보나루 키로 검색 결과가 나온다. 결과 없음과 오류 상태가 보인다. 응답 변환 로직에 테스트가 있다 | 실제 휴대폰에서 한글 키워드 검색 |
| F2 현재 위치 | 허용하면 S4 목록으로, 거부하면 S3로 간다. 다시 시도가 동작한다 | 실제 휴대폰(https 배포 주소)에서 허용과 거부를 각각 확인 |
| F3 거리순 목록 | 목록이 거리순이고 순번과 상태가 보인다. 거리 계산과 정렬 로직에 테스트가 있다 | 실제 위치에서 목록 1번이 실제로 가장 가까운 도서관인지, 아는 도서관 1곳의 상태가 도서관 홈페이지와 같은지 비교 |
| F4 도서관 상세 | 목록 항목을 누르면 시트가 열린다. 전화와 홈페이지 링크가 동작한다 | 휴대폰에서 전화 앱이 열리는지 확인 |
| F5 즐겨찾기 | 책과 도서관 모두 넣기/빼기가 새로고침 후에도 유지된다. 저장 로직에 테스트가 있다 | 휴대폰 브라우저를 닫았다 열어도 두 탭이 유지되는지 확인 |

## 8. 외부 API 확인 목록

추측하지 않고 실제 응답으로 확인한 뒤 이 표를 채운다.

| 항목 | 상태 | 확인 결과 |
|---|---|---|
| 정보나루 인증키 발급 | 활성화됨 (2026-10-29) | 2026-10-27에는 `{"response":{"errCode":"vitalizationErr","error":"API 활성화 상태가아닙니다."}}`. **오류도 HTTP 200으로 온다** → 상태 코드가 아니라 `response.error`로 실패를 판단해야 한다. 2026-10-29 정상 응답 확인 |
| 일일 호출 한도 | 하루 499건 | 사용자가 정보나루 마이페이지에서 확인 (2026-10-29). 응답에는 한도 정보가 없다. 한도를 넘었을 때의 응답은 미확인 |
| `libSrch` 응답 | 확인 | `libSrchByBook`과 같은 `libs[].lib` 형태에 `BookCount`가 더 있다. `pageSize=500`이면 한 번에 다 온다(경기 400곳). 2026-10-29 기준 17개 시도 합계 약 1,620곳, 받아 본 곳 중 좌표 없는 곳은 없었다. 런타임에는 부르지 않고 갱신 스크립트에서만 쓴다(9장 2026-11-03) |
| `bookExist` 오류 | 확인 | 없는 도서관 코드면 `{"errCode":"libCodeErr","error":"도서관 코드를 확인하시기 바랍니다."}` |
| `bookExist`가 대출 가능 여부도 주는지, 실시간인지 전날 기준인지 | 대출 가능 여부: 있음 / 기준 시각: 미확인 | `{"response":{"request":{...},"result":{"hasBook":"Y","loanAvailable":"Y"}}}`. 값은 `"Y"`/`"N"` 문자열. 응답에 기준 시각이 없다 → F3 직접 확인(도서관 홈페이지와 비교)으로 판단한다 |
| `libSrchByBook` 응답에 도서관 좌표(위도/경도)가 있는지 | 있음 | `response.libs[].lib` 안에 `libCode`, `libName`, `address`, `tel`, `fax`, `latitude`, `longitude`, `homepage`, `closed`, `operatingTime`. 좌표는 **문자열**(`"37.492994"`). `numFound`(전체 수), `resultNum`(이번 쪽 수). 소장 도서관이 없으면 `numFound: 0, libs: []`. `region`이 **필수**: 빼면 `{"errCode":"regionCodeErr","error":"지역코드를 확인해 주시기 바랍니다."}` |
| `region` 코드 체계 (위치 → 지역 코드 변환 방법) | 확인 | **정보나루 자체 코드**이고 법정동 코드와 다르다. 시도: 서울 11, 부산 21, 대구 22, 인천 23, 광주 24, 대전 25, 울산 26, 세종 29, 경기 31, 강원 32, 충북 33, 충남 34, 전북 35, 전남 36, 경북 37, 경남 38, 제주 39 (41, 50은 `regionCodeErr`). 시군구 `dtl_region`도 자체 코드(노원구 11110, 광진구 11050. 법정동 노원구 11350은 0건). `libSrchByBook`과 `pageSize=500`이면 서울 소장 293곳이 한 번에 온다. 변환 방법은 9장 결정 기록 |
| `srchBooks` 응답 필드 (표지, ISBN13 포함 여부) | 있음 | `response.numFound`(전체 수), `response.docs[].doc` 안에 `bookname`, `authors`, `publisher`, `publication_year`, `isbn13`, `bookImageURL`, `bookDtlUrl`, `loan_count`(문자열) 등. 기본 정렬은 대출 많은 순. 결과 없으면 `numFound: 0, docs: []`. `keyword` 하나로 제목과 저자가 함께 검색된다(`keyword=한강` → 저자 한강 책). 표지 주소가 **`http://`인 경우가 있다**(https 페이지에서 섞인 콘텐츠). `bookname`에 부제가 `:`로 붙고 끝에 공백이 있을 수 있다(`"작별하지 않는다 :한강 장편소설 "`), `authors`에 `지은이: ` 같은 접두가 붙을 수 있다 |
